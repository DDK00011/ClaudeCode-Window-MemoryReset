## Design highlights

### 1. system tray daemon = non-administrator + recovery trigger = administrator
- **daemon itself**: non-administrator (no UAC prompt, starts naturally at boot)
- **On recovery action click**: `MemoryReset.ps1` spawn → UAC elevation inside it
- This separation preserves security visibility during recovery without showing UAC every time at boot

### 2. Alert policy
- memory usage ≥ 90% (user-adjustable, 50~99) → BalloonTip
- **No automatic recovery** (guarantees user choice)
- 10-minute cooldown (spam prevention)

### 3. CSV schema (clarified in v1.2.1)
```
Timestamp, Mode, TotalMB,
UsedBeforeMB, UsedAfterMB, FreedMB,         ← positive = recovery success
BeforeFreeMB, AfterFreeMB,
BeforePctFree, AfterPctFree, FreedPctP,     ← positive = available % increase
ProcessesKilled, RuntimeSec
```

### Applied P1 patches

#### 1. Explicit STA thread declaration (Tray.bat)
- **Issue**: PS 5.1 default ApartmentState = MTA, but WinForms requires STA
- **Result**: OLE-backed controls like InputBox / OpenFileDialog can hang
- **Fix**: Add the `-Sta` flag to `Tray.bat`
- **Source**: [MS Docs STA](https://learn.microsoft.com/en-us/dotnet/api/system.stathreadattribute)

#### 2. Clarify CSV column names
- **Issue**: `RecoveredMB` is semantically confusing
  - Code uses `AfterFree - BeforeFree` (available memory increase)
  - Plain language says "recovered memory = reduced usage"
- **Fix**: Expand the schema
  - Add `TotalMB`
  - Add `UsedBeforeMB`, `UsedAfterMB`
  - `RecoveredMB` → `FreedMB` (= UsedBefore - UsedAfter)
  - `RecoveredPctP` → `FreedPctP`
- **Compatibility**: Added/renamed columns — existing CSV has a different header. Recommended to start with a new file.

#### 3. Fallback CSV same-second collision
- **Issue**: If `recovery-history-yyyyMMdd-HHmmss.csv` is created twice in the same second, `Export-Csv` (no -Append) overwrites it
- **Fix**:
  - Single date-based fallback: `recovery-history-fallback-yyyyMMdd.csv` + `-Append`
  - In emergencies (fallback lock too): `recovery-history-emergency-yyyyMMdd-HHmmss-fff-{4-char GUID}.csv` (0% collision)

### Verified items (external sources)

- **Application.Run message loop**: NotifyIcon.Visible=$true is OK before Run() ([MS Docs](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.notifyicon.visible))
- **InputBox modal blocking**: Message pumping on the same STA thread → tray does not freeze ([MS Docs](https://learn.microsoft.com/en-us/dotnet/api/microsoft.visualbasic.interaction.inputbox))
- **NotifyIcon.Text 63-character limit**: NOTIFYICONDATA.szTip Win32 API limit is correct
- **Export-Csv -Append PS 5.1**: Properly avoids duplicate headers
- **mutex `Local\`**: User-session isolation + separate instances under RDP/Fast User Switching (intentional)
